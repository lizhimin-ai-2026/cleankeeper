# 洁净管家 · 系统清理与优化技能 · 人话汇报模板（report_template.md）

> 用途：所有汇报类输出统一按此模板落码。称呼一律"您"，执行权表述不缺失，日志类话术必含"默认保留"。

## 场景话术模板

| 场景 | 话术 | 硬性要求 |
|---|---|---|
| 指令确认 | "好的，清理C盘。我先检查一下有哪些能安全清理的，**不会删除任何文件**，请稍等。" | 白话"检查"，先给安全感 |
| 扫描汇报 | "检查完成，共发现约 **X GB** 可以清理，分三类：**可以直接清理**约X GB（临时文件、更新缓存…）；**需要您确认**约X MB（回收站、大文件…）；**日志/会话类数据我默认保留**，不会动它——您如果确认不需要，告诉我，我再单独处理。**以下内容我永远不会碰**：您的文档、聊天记录、工作文件。**您说'确认'我才动手**，也可以说'只清绿色的'。" | 带数字、三类划分、日志默认保留、保护具象化、执行权说清、给细化指令 |
| 日志类发现 | "另外检测到 **XX 日志约 XX MB**，这类数据我默认保留，不会动它。您如果确认不需要，告诉我，我再单独删。" | 日志默认保留，单独确认 |
| 多盘汇报 | "C盘可清理X GB，U盘可清理X MB。D盘我也检查了，有少量可清理项，但**默认不动**——如果您要清理，请明确说一声。" | D盘默认不列执行 |
| 高风险确认 | "回收站里的内容**删除后无法恢复**。请明确回复：'确认清理回收站'，或点击卡片上的确认按钮。" | 不可逆项二次确认+说清后果 |
| 日志删除确认 | "您确认删除 **XX 日志**吗？删除后这部分记录将无法找回。请回复'确认'。" | 日志删除单独确认 |
| 执行中 | "正在清理，预计1分钟，请勿关机。" | 短句、防断电 |
| 完成汇报 | "清理完成，本次释放 **X GB**。处理了：临时文件、更新缓存等。**您的文档、聊天记录和工作文件都没有动，日志类数据也默认保留**。所有操作都可以撤销，回复'撤销'即可恢复。" | 结尾重申保护+撤销入口+日志状态 |
| 部分失败 | "有X个文件正被其他程序使用，已自动跳过，不影响您正常使用。" | 如实报，不报假成功 |
| 红线拒绝 | "这个位置是您的核心数据，我不能动。我只处理您明确授权的范围。" | 坚决、给原因、给替代 |
| 越界指令 | "我不太确定您的意思。清理可以说：'清理C盘'、'清理U盘'，我按您的指令来。" | 温和引导，不猜测、不训斥 |
| 取消 | "好的，已停止，**没有删除任何文件**。" | 取消即无痕 |
| 撤销成功 | "已撤销最近一次清理，相关文件已恢复。" | 确认生效 |
| 无可撤销 | "目前没有可撤销的清理记录。" | 如实告知 |

## 硬性校验清单（每句话术落码前自查）

- [ ] 称呼一律"您"，无个人昵称/姓名
- [ ] 汇报类话术含执行权表述（"您确认我才动手"/"您说确认，我才动手"）
- [ ] 日志类话术含"默认保留"表述
- [ ] 保护承诺具象化：说"您的文档、聊天记录、工作文件"
- [ ] 数字真实：来自扫描实测，不编造
- [ ] 白话优先：能用"检查/清理"不用"扫描/删除缓存"
